Zeus heeft een gloednieuwe chatserver, maar oh nee, nog niemand kan ermee communiceren! Kan jij het protocol van de server implementeren?

Het protocol is niet zo moeilijk, maar je zult wel zelf code moeten schrijven om ermee te communiceren en een reeks opdrachten te volbrengen.
Als dit je lukt, spreek je officieel het Zeusprotocol (van dit jaar)!
